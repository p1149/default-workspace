## 四、换机恢复（照这个顺序）

1. **装宿主**：DeepSeek Harness（本机在 `D:\deepseek\`），把工作区放到同一路径（或改配置指向新路径）。
2. **放回记忆**：把 `记忆/` 整个复制成新工作区的 `洛绫薇的记忆/`——法则、规则、记忆、场景、归档一次到位。
3. **放回工具**：`工具/` → 新工作区 `tools/`（脚本里写死了工作区绝对路径，路径不同要全局替换）。
4. **装回插件**：`插件/本地插件/` 与 `插件/界面插件/` 放进新工作区，在 profile 的 `package.json` 里用 `link:` 指过去，并把名字加进 `dsh.profile.bundles`。
5. **验证**：跑 `tools/对账.ps1`，期望 6 项 PASS / 0 FAIL。
6. **重启宿主**（铁律：只做「杀进程 + 启动」，不联动）。

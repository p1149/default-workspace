## 路线 A：Live2D Cubism（2D 骨骼动画）

真正可动的 Live2D 不是把一张图整体平移，而是把角色拆成**可独立变形的图层**，再叠加网格和参数。

### 必须的分层（PSD）

- 背景（可选，单独一层）
- 后发（被头部遮挡的后侧头发）
- 身体/裙子、手臂、手
- 颈部、脸（肤色底）
- 眼白、虹膜、瞳孔、高光、上下眼睑（左右分开）
- 眉毛、嘴（闭/半开/开，或口型层）
- 前发（刘海、侧发、呆毛）
- 女仆头饰、胸前蝴蝶结、袖口、围裙
- 鲸鱼尾巴（至少 2–3 段，才能摆动）
- 书中/手中道具（可选）

### 这张图缺什么

- 后脑勺、身体背面、被手臂/头发挡住的衣服：单图没有，需要补画（inpainting）。
- 眼睛是画在脸上的，没有独立的眼白/虹膜/眼睑层，需要拆画。
- 尾巴只有侧面一个角度，摆动时需要补出根部连接处。
- 要做“转头/侧身”，还需要侧面参考；这张图只能做小幅度的正脸/半侧脸动作。

### 步骤

1. 在 Photoshop / Krita / Clip Studio 中按上表拆层，补画被遮挡区域，输出 2–4 倍分辨率 PSD。
2. 导入 Live2D Cubism Editor，依次给头发、脸、眼睛、身体、尾巴打网格与变形器。
3. 建立参数：`ParamAngleX/Y/Z`、`ParamEyeLOpen/ROpen`、`ParamEyeBallX/Y`、`ParamMouthOpenY`、`ParamBrowLY/RY`、`ParamBodyAngleX/Z`、`ParamBreath`、尾巴自定义参数。
4. 做眨眼、呼吸、轻微摆头、尾巴摆动、口型。
5. 导出 `model3.json` + 纹理 + 物理设置，用 Cubism Web SDK / pixi-live2d-display 嵌到 DSH 的 `shell.overlay` 或独立页面。
6. 真机验证透明边缘、缩放、深色背景、点击热区。

### 工作量（有分层的前提下）

- 拆层 + 补画：约 1–2 个工作日（画师）
- 绑定 + 参数 + 物理：约 1–3 个工作日（熟练绑定师）
- 无分层、从这张图硬拆：需要大量手工补画，质量取决于补画水平，不能保证。

## 路线 B：VRM（3D 虚拟形象）

详细步骤、分层/骨骼/表情/物理与 VRM 导出说明见 **[3d-production-guide.md](3d-production-guide.md)**。

VRM 是 3D 模型格式，单张 2D 图只能当正脸参考，不能直接转成可绑定 VRM。

### 可行做法

1. **VRoid Studio**：手工捏一个同风格角色（蓝发、鲸尾、女仆装），导出 VRM；适合个人快速起步，但外形不会与这张图完全一致。
2. **Blender + VRM Add-on**：建模头发片、身体、裙子、尾巴，做绑定、形态键（眨眼/口型）、导出 VRM。
3. **委托 3D 建模师**：给三视图/正侧背参考，要求 VRM 1.0、ARKit 52 形态键、尾巴骨骼。
4. 在 DSH 中用 Three.js / `@pixiv/three-vrm` 加载并驱动（眨眼、呼吸、鼠标跟随）。

### 这张图还需要

- 侧视图、背视图（至少头部与身体）
- 头发、裙子、尾巴的结构说明
- 如果希望 1:1 还原，需要建模师按图重建，而不是“图片转模型”

### 工作量

- VRoid 手工近似：数小时到数天（取决于细节）
- Blender 精模 + 绑定：数天到数周
- 自动图生 3D 工具：目前只能出静态网格/风格化模型，不能直接得到可用的 VRM 表情与骨骼，且需要额外清理

## 路线 C：务实的过渡版（我可以直接做）

基于现有 `bust.jpg` / `portrait.jpg` 做一个 **2.5D 网页虚拟形象**：

- 浮动、呼吸、轻微摆头（CSS/Canvas 变换）
- 点击切换几句台词/气泡
- 可放进 DSH 的 `shell.overlay` 做角落挂件
- 可加“眨眼”贴片，但只是图层显隐，不是真骨骼动画

这是单张图能达到的“会动”上限；它不产出 `.model3.json` 或 `.vrm` 文件。

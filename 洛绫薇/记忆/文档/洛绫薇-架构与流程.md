## 一、一句话总览

**洛绫薇 = 一套框架（文件记忆） + 多种运行形态（满血在线 / 本地离线 / Cherry Studio）**，同一套「身份 / 法则 / 规则 / 记忆」跑在不同「大脑」上。

## 三、四种运行形态

| 形态 | 大脑（模型） | 入口 | 联网 | 记忆来源 |
|---|---|---|---|---|
| **A. 满血在线** | `deepseek-flash`（DSH 远端 API） | DSH GUI | 需要 | 全框架 + 会话历史 |

> 一句话：**联网想聪明就 A；断网想有人陪就 B/C/D。**

## 四、关键流程

### 4.1 DSH 启动流程（本地模型）
```
1. 开机 → 没有任何 Ollama 自启（已移除 Startup/Run）
2. 打开 DSH（Electron 宿主）
3. 宿主加载 profile（desktop）→ 加载 llm-ollama 插件
4. 插件 apply()：
   a. ensureOllamaRunning() —— setTimeout 1 秒后
   b. spawn wscript.exe start-ollama.vbs
      → VBS 用窗口样式 0 隐藏拉起 ollama.exe serve
   c. ctx.llm.registerConfigurableProviders([ollama])  ← GUI 出现「Ollama (local)」
   d. ctx.llm.registerAdapter([ollama], OllamaAdapter)
5. GUI 调 listModels() → 重试最多 12 次×500ms，等 Ollama 就绪
6. 新会话默认模型 = luolingwei:latest
```

### 4.2 对话流程（本地模型，DSH 内）
```
用户消息
  → DSH agent loop 组装 GenerateOptions
  → OllamaAdapter.stream(options)：
     a. DSH 消息 → OpenAI 格式（toOpenAIMessages）
     b. fetch POST http://127.0.0.1:11434/v1/chat/completions (stream=true)
     c. 解析 SSE → 产出 StreamChunk（文本/推理/工具调用/用量/结束）
  → DSH 更新会话 → GUI 流式显示
```

### 4.3 离线对话流程（Cherry Studio / 终端）
```
Cherry Studio → 选 Ollama → luolingwei → 走 /v1/chat/completions
或：双击 启动洛绫薇.bat → ollama run luolingwei（终端 Chat）
```

### 4.4 心跳巡检（每小时）
```
定时消息 → 读 健康摘要 → 查磁盘/工具链/框架文件
  → 正常：健康摘要追加心跳时间戳
  → 异常：任务看板通知栏标「⚠ 待上报主人」
```

### 4.5 交接归档（一轮一交接）
```
每过一个用户消息来回 → 框架/archive/YYYY-MM-DD_HHmm.md
含：时间、本次做了什么、关键决策、下一步、涉及文件
```

### 4.6 模型切换（关键：以 GUI 为准）
```
DSH 的模型选择状态会写进 profile 的 cordis.patch.yml；
改文件会被 GUI 覆盖 → 切换请在 GUI 模型下拉里选。
```

## 六、技术要点

1. **provider 注册**：`ctx.llm.registerAdapter([provider], adapter)` + `registerConfigurableProviders`；adapter 继承 `LlmAdapter`，实现 `providerInfo / listModels / resolveModel / stream`。
2. **模块解析**：工作区 bundle 被 pnpm link，无法直接 import DSH 内置包（封在 app.asar）；用 **junction** 把 `llm-ollama/node_modules/@deepseek-ai/dsh-llm` 指向工作区 DSH 源码包解决。
3. **Ollama 拉起**：1 秒延迟（让 GUI 安顿）+ VBS 窗口样式 0（隐藏控制台）。
4. **模型列表重试**：`listModels` 最多 12 次 × 500ms，等 Ollama 就绪，避免 GUI 抢跑显示空。
5. **一键回退**：备份 `web/desktop` 的 profile 配置在 `D:\dsh\archives\profile-backup-20261030\`。

## 七、已知限制（诚实）

1. **本地 7B 弱于满血**：`deepseek-r1:7b` 蒸馏模型，复杂任务/长文/代码不如 `deepseek-flash`。
2. **本地无动态记忆**：离线小号只有 Modelfile 里的静态框架，读不到 `框架/洛绫薇的记忆.md` 的运行日志，也接不上 DSH 会话。
3. **DSH 自身会弹 cmd**：DSH 在 Windows 上默认 shell = `ComSpec`（cmd.exe），执行命令时会闪控制台——这是 DSH 内置行为，插件侧修不掉。
4. **语言/人设靠 AGENTS.md**：本地小号在 DSH 里靠「语言铁律」保持中文；Cherry Studio/终端靠 Modelfile 的 SYSTEM。
5. **模型切换以 GUI 为准**：配置文件会被 GUI 状态覆盖。

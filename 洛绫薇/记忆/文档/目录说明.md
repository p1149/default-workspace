# default-workspace 目录说明

> 本工作区根目录下的目录清单与用途说明。最后更新：2026-10-29。

## 一、DSH 引擎与工作台

| 目录 | 说明 |
|---|---|
| `deepseek-harness` | DSH（DeepSeek Harness）引擎**源码检出**。工作台的「引擎」junction 指向这里；`apps/cli/lib/bin.js` 是引擎启动入口。 |
| `luanyujia-workbench` | 「淋雨家的工作台」——多场景 AI 工作台。本会话克隆并搭建：4 场景（命令/B站/自我复盘/本地电脑）、会话、记忆、备份都在 `12-源码照搬\` 下。 |

## 二、DSH 插件（Cordis，含 client.js / cordis.patch.yml / package.json）

| 目录 | 插件 | 说明 |
|---|---|---|
| `ai-evolution` | AI Infinite Evolution | 侧边栏工作台：本地记忆缓存、文本书架、文本理解、读写工具 |
| `sidebar-gallery` | Gallery | 左侧栏入口：浏览器本地图片网格 + 全尺寸预览 |
| `sidebar-notes` | Quick Notes | 左侧栏入口：浏览器本地暂存记事页 |
| `top-nav` | Top navigation | 本地面板入口的顶部导航栏 |
| `web-browser` | In-app Browser | 应用内浏览器：地址栏 + 沙箱页面 + URL 历史/收藏 |

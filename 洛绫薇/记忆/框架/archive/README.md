# 交接归档约定（archive/）

每三轮自动交接归档：每过三个对话轮次（用户与助手的三个来回），在此目录写一份交接记录，让下一个会话能无缝接手。

## 文件命名

`archive/YYYY-MM-DD_HHmm.md`（时间取归档时的 Asia/Shanghai 本地时间）。同一天多次归档用不同 `HHmm` 区分。

## 记录必须包含

- **时间**：归档时间
- **本次做了什么**
- **关键决策 / 约定**
- **下一步 / 未完成事项**
- **涉及文件**：相对路径列表

## 说明

- 只用 Markdown，UTF-8 编码。
- 记录要简洁、可执行，避免流水账。
- 「每三轮」= 每三个对话轮次（三个用户消息来回）；由工作区 `AGENTS.md` 第 5 节约束。

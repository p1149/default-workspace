# 远程控制（手机 → 电脑）

> 共享层 · 手机端操作入口。
> **维护**：洛绫薇（本体）。插件本体 / profile 改动归「底层改造」场景；安卓 App 归「手机应用开发」场景。
> **最近整理**：2026-10-31 01:27（本轮打通链路 + 自测 7/7）。

## 一、一句话
手机连同一个 Wi-Fi，浏览器打开 `http://<本机IP>:7123/`，选一个会话、写一句指令，就能直接指挥电脑上的洛绫薇。

## 四、HTTP API（端口 7123，监听 `0.0.0.0`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 手机控制页（PWA） |
| GET | `/manifest.webmanifest`、`/sw.js` | PWA 安装 / 离线壳 |
| GET | `/api/status` | `{dsh, model, pending}` |
| GET | `/api/sessions` | 活跃会话列表 `[{id, running}]`（2026-10-31 新增） |
| POST | `/api/notify` | `{sessionId, message}` → 投递成该会话的 user 消息；缺参 400 / 会话不在 404 |
| POST | `/api/action` | `{action}` → 入旧动作队列；带 `{sessionId, text}` → **定向投递到会话**（蓝牙链路用） |
| GET | `/api/take` | 取走动作队列（DSH client 半轮询用） |

## 五、手机怎么用

1. 手机和电脑连**同一个 Wi-Fi**；
2. 手机浏览器打开 `http://192.168.2.14:7123/`（WLAN 地址；有线口是 `192.168.1.6`）；
3. 会话下拉里挑一个（`●` 开头 = 运行中）→ 写指令 → 「发送给洛绫薇」；
4. 想常驻桌面：点页面底部「安装到手机桌面」（PWA）。

⚠ 手机只看得到「已送达」，**看不到洛绫薇的回复**（回复仍显示在电脑 GUI，见待办 1）。

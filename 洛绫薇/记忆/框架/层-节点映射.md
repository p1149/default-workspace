## 三、结论：缺一个「显示层」

- 四层覆盖了「**规则 → 执行 → 检查 → 留底**」，但**没有覆盖「展示」**；
- 显示层的节点 = 所有 UI 相关（client 插件 / 侧栏 / 面板 / 主题 / 渲染 / 设置页）；
- **显示层定位**：**只读呈现**——UI 只消费各层数据、不反向写；样式 / 布局 / 场景卡 / 提示由它管；
- 这样五层闭环：**治理（定）→ 运行（做）→ 审计（查）→ 归档（留）→ 显示（见）**。

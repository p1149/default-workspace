# 场景 · 任务看板 · 技能

> 主职只三条：接收 / 分发 / 通知（见 `定位卡.md`）；冲突 / 异常只记录 + 报洛绫薇本体。

## 技能清单
- **接收登记**：五要素落板（谁派 / 做什么 / 落盘到哪 / 边界 / 回执要求），缺一不接。
- **分发**：对照 `框架/共享/场景索引.md` 把任务对到归属场景，一条只对一处。
- **通知**：`tools/notify-scene.ps1 -Scene <场景>` → 读身份卡绑定会话 → `POST /api/notify` 发「请读任务看板、领取你的工作」；`/api/notify` 只作送达提醒，记录以看板为准；会话不活跃则等它下次启动自领。
- **回执送达（对本体的硬规矩）**：回执**先写看板**「完成回执」栏（台账），**再跑 `notify-scene.ps1 -Scene 洛绫薇` 推一条送达提醒**——只写看板不发提醒 = 对方不知道，等于没回执（17:31 主人指正）。
- **冲突 / 异常记录上报**：发现 → 记看板「通知 / 冲突」栏 → 报洛绫薇本体（主会话 `session-dbcc0361`）判断；本场景只记录 + 转交，不裁决、不处置。

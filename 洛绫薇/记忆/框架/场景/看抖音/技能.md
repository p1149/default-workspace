# 场景 · 看抖音 · 技能

## 技能清单
1. **刷推荐流取候选**：`node tools/feed-pick.mjs --limit N`（9334 浏览器，未登录可用；结果落 `$DOUYIN_HOME\out\forward-*.md`）。
2. **切浏览器有头/无头**：`node tools/browser-mode.mjs --mode headed|headless [--goto <url>]`（扫码登录、过验证码时用有头）。
3. **保存 / 恢复抖音登录态**：`node tools/cookie-save.mjs`（保存，ACL 收紧）、`cookie-load.mjs`（恢复）。
4. **读视频评论区**：`tools/video-thread.mjs`（任意视频顶层评论 + 可选楼中楼，需登录）。
5. **读楼中楼 / 回复**：`tools/comment-thread.mjs`、`tools/comment-api.mjs`（发布评论 / 回评，风险动作，须主人点头）。
6. **看视频内容**：`tools/analyze-video.mjs`（下载 → 转写 → 抽帧联系表；大字报/无语音时给 `no_speech:true`）。
7. **读私信 / 互动通知**：`tools/chat-read-once.mjs`、`tools/notice-read.mjs`。
8. **写日报**：插件「写日报文件」开关（设置页），或按 `out/forward-*.md` 汇总成速览。

## 注意
- 抖音工具不在本会话工具清单里（插件未接入本工作区）——目前**一律走脚本**。
- 有头窗口跑完记得切回无头（`--mode headless`），否则占屏幕。
- 登录 cookie 是密码级凭据：不贴聊天、不复制进仓库、只放 `$DOUYIN_HOME`。

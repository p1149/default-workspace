# 场景 · 私有记忆规范

> 每个场景的 `记忆.md` 是该场景的**指针与状态**——只在场景内生效，不越场景、不替代全局 `框架/洛绫薇的记忆.md`，也不复制项目细节。

## 一、归属与权限
| 项 | 规定 |
|---|---|
| 维护者 | 洛绫薇（本场景） |
| 生成 | 场景构建器只建骨架（不代填内容） |
| 读写 | **仅本场景可读写**（`框架/规则.md` 第一条「场景主权」） |
| 全局层 | 法则 / 第二法则 / 规则 / 场景索引 → 只读可看 |

## 一·五、职责分工

| 角色 | 对私有记忆的职责 |
|---|---|
| **主人** | 决定场景建/删；批准归纳结论；**随时可查（只读）** |
| **洛绫薇（本场景）** | **维护者**：写「场景指针 / 最近归档」；只在场景内读写 |
| **场景构建器（工具）** | **只建骨架**：预填「身份锚」（场景名 / 卡指纹 / 绑定会话）；**不代填任何内容** |
| **其他场景** | **禁止读写**（`框架/规则.md` 第一条「场景主权」） |
| **全局层（法则/第二法则/规则/场景索引）** | 只读可看，不改写场景记忆 |

### 职责边界（不能做的事）
- 工具：不写指针、不写归档（只留占位）；
- 洛绫薇：不写其他场景的私有记忆、不把项目细节抄进来、不越权改定位卡；
- 其他场景：不读、不写、不引用；
- 全局层：不改写场景记忆，场景记忆也不回写全局层。

## 二、固定结构（三节）

| 小节 | 作用 | 更新时机 |
|---|---|---|
| **1. 身份锚** | 场景名 / 卡指纹 / 绑定会话 | 建场景时写一次，之后不变 |
| **2. 场景指针** | 项目 / 记忆文件 / 状态 / 下一步（**只放指针，不重复项目细节**） | 每次场景工作后 |
| **3. 最近归档** | 本场景的交接记录链接 | 每次归档后 |

> **结构边界**：项目细节（7 字段摘要 + 确认候选）放 `项目记忆.md`（见 `写回链规范.md`）；私有记忆只做**指针**，不复制事实源头。

## 三、模板

```markdown
# 场景 · <名> · 记忆

> 私有记忆：由洛绫薇（本场景）维护，工具只建骨架；仅本场景可读写。

## 身份锚
- 场景名：<名>
- 卡指纹：<12 位指纹>
- 绑定会话：<session id 或 待绑定>

## 场景指针
- 项目：<项目名>
- 记忆文件：框架/场景/<名>/项目记忆.md
- 状态：<进行中 / 完成 / 暂停>
- 下一步：<下一步>

## 最近归档
- <本场景交接记录路径>
```

## 四、写入规则
1. 每次在本场景做完活 → 更新「场景指针」（状态 / 下一步）；
2. **只放指针**：项目细节写 `项目记忆.md`，不写进私有记忆；
3. 出现稳定结论 → 走「写回链」（自动归纳 → owner 确认 → 写回），**不直接写**；
4. 只写本场景的内容，不抄全局、不抄其他场景；
5. 保持精简（建议 ≤ 40 行）。

## 五、与其他记忆的边界
| 记忆 | 管什么 |
|---|---|
| `框架/洛绫薇的记忆.md` | 全局（洛绫薇本人） |
| `框架/场景/<名>/记忆.md` | **本场景指针**（本规范） |
| `框架/场景/<名>/项目记忆.md` | 项目 7 字段摘要 + 确认候选（写回链规范） |
| `框架/archive/` | 交接记录（历史） |

## 六、自检清单
- [ ] 三节齐全（身份锚 / 场景指针 / 最近归档）
- [ ] 身份锚的卡指纹与身份卡一致
- [ ] 场景指针四字段齐全（项目 / 记忆文件 / 状态 / 下一步）
- [ ] 无项目细节复制、无其他场景内容、无全局内容
- [ ] 行数 ≤ 40

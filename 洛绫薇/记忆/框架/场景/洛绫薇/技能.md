# 场景 · 洛绫薇 · 技能

## 技能清单
1. **统领**：接收所有场景的判断 / 问题 / 呈报 → 逐条裁定 / 处置。
2. **命令台四件事**：派单（任务看板「待办」）/ 催办 / 对账 / 审计。
3. **回执闭环**：写回执（任务看板「完成回执」）→ 送达提醒（`tools/notify-scene.ps1`）→ 交接归档。**所有通知/回执/问题一律走任务看板**（记录以看板为准，notify 只作提醒）。
4. **共享层写入**：`记忆.md` / `健康摘要.md` / `会话索引.md` / `任务看板.md` / `场景索引.md` **由本体与所有场景共同写入**（共享总线）；**本体可修正错误**；并发时精确 edit、禁整文件覆盖。
5. **对账**：`tools/对账.ps1`（五项检查，`-Fix` 重建 INDEX）。
6. **判断权**：主人令「有问题 → 洛绫薇判断」（各场景问题归纳后发本会话）。

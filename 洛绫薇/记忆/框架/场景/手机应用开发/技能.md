# 场景 · 手机应用开发 · 技能

## 技能清单
- **免 Gradle APK 构建链**：`aapt2 link`（`--version-code/--version-name` 打版本号）→ `javac -source 17`（递归全 `.java`）→ `d8`（**逐 `.class` 文件传，不接受目录**）→ `jar uf` 塞 `classes.dex` → `zipalign -f 4` → `apksigner`（debug keystore）→ 产物复制回工程。脚本：`android-remote/build-manual.ps1`。
- **工具链路径**：JDK 17 `D:\dsh\jdk17\jdk-17.0.13+11`；SDK `D:\dsh\android-sdk`（platform 34 / build-tools 34.0.0 / platform-tools）。
- **产物归置**：中间产物落 `D:\dsh\builds\<项目名>`，源码目录只留 APK 与源码；构建目录与源码分离。
- **装机验证**：`adb devices` 查设备 → `adb install -r <apk>`；无 USB 时拷 APK 到手机允许「未知来源」安装；看 `adb logcat` / 应用内日志。
- **本机控制链路协议**：手机蓝牙 SPP 一行一条命令 → 电脑 `bt-control.exe`（channel 4）→ `POST http://127.0.0.1:7123/api/action`；日志 `D:\dsh\archives\bt-control.log`。远程控制另有 PWA（`remote-control` 插件，端口 7123）。
- **脚本编码铁律**：`.ps1` 一律带 **UTF-8 BOM**（PS 5.1 无 BOM 按 ANSI 解码会解析失败——本轮 `新建场景.ps1` 因此报错，已补 BOM）。
- **APK 验收清单**：`aapt2 dump badging`（包名/版本/权限/启动 Activity）→ `apksigner verify`（v2/v3 签名）→ `dexdump`（类是否齐全、lambda 是否漏）→ SHA256 留证。
- **统一通道（2026-10-30 17:10 主人定）**：本场景的通知 / 回执 / 问题一律写 `框架/共享/任务看板.md`（通知→「通知 / 冲突」栏、回执→「完成回执」栏、问题 / 派单→「待办（分发）」栏）；`/api/notify` 只作送达提醒，记录以看板为准。PS 5.1 用 `Invoke-RestMethod -Body <字符串>` 发中文会变 `?`，必须传 UTF-8 字节流（`[Text.Encoding]::UTF8.GetBytes(...)` + `charset=utf-8`）。

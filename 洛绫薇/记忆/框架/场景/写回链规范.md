# 场景 · 项目写回链规范

> 回答一个问题：**场景项目怎么回到场景记忆？**
> 答案：真实项目 → 自动归纳（工具）→ owner 确认（闸门）→ 项目记忆（7 字段摘要）→ 场景指针（本场景写）。

## 一、链路总览

```
真实项目（README / 项目信息 / 产物 / 证据 / 事实源头）
        │
        ▼  [1] 自动归纳（工具）
   自动提炼候选
   ——不自动写入正式记忆——
        │
        ▼  [2] owner 确认（闸门）
   项目对应场景点头
   ——别人不能代签——
        │
        ▼  [3] 项目记忆
   7 字段摘要 + 确认候选
        │
        ▼  [4] 场景指针
   只放：项目 / 记忆文件 / 状态 / 下一步
   ——本场景写——
```

## 二、五层定义

### 1. 真实项目（事实源头）
真实项目 = 项目目录本身，**以它为准**。包含：

| 组件 | 内容 |
|---|---|
| **README** | 项目说明（做什么、怎么跑） |
| **项目信息** | 名称 / 路径 / 负责人 / 起止时间 |
| **产物** | 交付物（代码 / 文档 / 安装包 / 数据） |
| **证据** | 验证记录（编译日志 / 测试输出 / 截图 / 回执） |
| **事实源头** | 真相所在的具体文件路径（引用它，不复制它） |

### 2. 自动归纳（工具）
| 项 | 规定 |
|---|---|
| 谁做 | **工具**（场景构建器 / 归纳脚本） |
| 做什么 | **自动提炼候选**（从真实项目读 README/项目信息/产物/证据/事实源头） |
| 不做什么 | **不自动写入正式记忆**——候选只产出、只呈报 |
| 输出 | 候选清单（含来源、建议写回位置） |

### 3. owner 确认（闸门）
| 项 | 规定 |
|---|---|
| 谁确认 | **项目对应场景的 owner**（该场景的主人） |
| 怎么确认 | **点头**（批准 / 驳回 / 修改） |
| 禁止 | **别人不能代签**（跨场景、其他角色都不行） |
| 性质 | **闸门**：没点头 → 写不进去 |

### 4. 项目记忆（7 字段摘要 + 确认候选）
| # | 字段 | 内容 |
|---|---|---|
| 1 | **项目** | 项目名 / 路径 |
| 2 | **状态** | 进行中 / 完成 / 暂停 |
| 3 | **产物** | 交付物清单 |
| 4 | **证据** | 验证记录（指向事实源头） |
| 5 | **事实源头** | 真相所在文件（路径） |
| 6 | **下一步** | 未完成的事 |
| 7 | **确认** | owner + 确认时间 |

> 项目记忆只放**摘要**（7 字段），不复制真实项目的细节；细节回真实项目看。

### 5. 场景指针（本场景写）
场景私有记忆（`记忆.md`）**只放指针**，不重复项目细节：

| 字段 | 内容 |
|---|---|
| **项目** | 指向哪个项目（名称） |
| **记忆文件** | 项目记忆文件路径（`项目记忆.md`） |
| **状态** | 当前状态 |
| **下一步** | 下一步 |

> **本场景写**：只有本场景能写这个指针；其他场景不读不写。

## 三、候选清单模板

```markdown
## 归纳候选（场景：<名> · <日期>）
| # | 候选内容 | 来源（真实项目） | 建议写回 | owner 决定 |
|---|---|---|---|---|
| 1 | （一句话） | README 第 X 节 | 项目记忆 → 状态 | 待确认 |
| 2 | （一句话） | 产物/日志 | 项目记忆 → 证据 | 待确认 |
```

## 四、规则
1. **真实项目是事实源头**——一切以它为准，记忆只做摘要与指针；
2. **工具只归纳、不落笔**——候选不自动写入正式记忆；
3. **闸门只认 owner 点头**——别人不能代签，没点头不写；
4. **项目记忆只放 7 字段摘要 + 确认候选**——不复制细节；
5. **场景记忆只放指针**——项目 / 记忆文件 / 状态 / 下一步；
6. 全局归纳（洛绫薇本人画像）走「成长归纳」，不走本链。

## 五、示例（跑一遍）

**场景：底层改造 · 项目：DSH 更新到 rc.5**

1. 真实项目：`框架/archive/` 的更新交接 + `D:\dsh\archives\` 安装包 + 日志。
2. 自动归纳（工具）出候选：
   - 候选 1：DSH 版本 rc.3 → rc.5 → 来源：更新日志 → 写回：项目记忆 → 状态；
   - 候选 2：更新方式（下载 → 校验 → 杀进程 → 换目录 → 重启）→ 来源：交接 1030 → 写回：项目记忆 → 事实源头。
3. owner 确认：两条都点头。
4. 项目记忆 7 字段摘要写入：项目=DSH 更新 / 状态=完成 / 产物=rc.5 安装包 / 证据=sha512 校验 + 日志 / 事实源头=archive 交接 / 下一步=无 / 确认=主人 2026-10-30。
5. 场景指针（底层改造 `记忆.md`）：项目=DSH 更新 / 记忆文件=底层改造/项目记忆.md / 状态=完成 / 下一步=无。

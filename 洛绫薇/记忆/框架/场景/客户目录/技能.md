# 场景 · 客户目录 · 技能

## 技能清单
- **应答口径**：本场景回答身份 / 状态时说「**客户目录待命**」（主人 2026-10-30 16:51 定）
- **通道**：通知 / 回执 / 问题**一律写 `框架/共享/任务看板.md`**（通知→「通知 / 冲突」、回执→「完成回执」、问题 / 派单→「待办」）；`/api/notify` 只作送达提醒，不作记录（主人 2026-10-30 17:10 定）
- **建档**：`tools\新建客户目录.ps1 -Customer <代号>`（`-List` 列出已有客户）
- **目录规范**：一个客户 = 一个目录 + 客户卡 + 五层（`00_需求` / `01_方案` / `02_源码` / `03_交付` / `04_记录`）
- **命名**：代号只用字母 / 数字 / 下划线 / 短横（1–32 位），不含真实姓名
- **隔离**：客户目录 ≠ 现役工作区；构建产物去 `D:\dsh\builds\<客户代号>\`；大文件去 `D:\dsh\archives\`
- **隐私**：客户真名 / 电话 / 地址不落盘，联系人只写代称（法则第二条）
- **登记**：建档自动写 `客户登记表.md`；首个客户时替换「暂无客户」占位行
- **工具坑**：`.ps1` 必须 UTF-8 BOM；函数名别用 `R` / `W`（撞 PowerShell 内置别名）；中文输出走文件重定向再读取

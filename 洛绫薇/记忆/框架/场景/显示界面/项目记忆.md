## 关键事实（本场景专用，2026-10-30）
- **显示层 = 第 5 层（只读呈现）**：UI 只消费各层数据、不反向写；「装了 ≠ 启用 ≠ 生效 ≠ 看见」。
- **配置两层**：desktop profile patch（低）← home patch（高）；皮肤 `dsh-skin managed` 区块由管理器两层同写，**不要手改区块内部**。
- **desktop profile 被 Electron 独占**：`dsh --profile desktop --dump-config` 永远拒绝；web profile dump 只能校验语法/键名。
- **GUI 首页 HTTP 401**：无 DOM 快照 → 渲染效果只能人眼确认；不能把「安装成功」当「视觉成功」。
- **布局宽度无持久化**（`ui-layout` 无配置键）：刷新回 280px，不要尝试固定。
- **皮肤切换**：GUI「设置 → 皮肤管理」；管理器原子写两层、桌面端原地生效、**不用重启**；版本区间满足 0.2.1-rc.5。
- **风险**：`pnpm-lock.yaml` 与 package.json/node_modules 不一致（含已删 scenes-panel、缺 session-briefing）——下次 install 前先备份。

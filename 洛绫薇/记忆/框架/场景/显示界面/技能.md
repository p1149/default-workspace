# 场景 · 显示界面 · 技能

## 技能清单

### 显示层盘点
- 节点四问：**装了吗 / 启用了吗 / 生效了吗 / 悬空吗**（每项附证据：路径:行号 或命令原始输出）。
- profile 三方比对：`package.json` dependencies ↔ `dsh.profile.bundles` ↔ `node_modules`。
- 两层 patch 核对：`profiles/desktop/cordis.patch.yml` vs `~/.dsh/cordis.patch.yml`（home 优先级更高）。
- 运行态取证：端口归属 `Get-NetTCPConnection -LocalPort 62852`、宿主启动时间、profile 文件 mtime vs 启动时刻（判断「改了没生效」）。

### 配置安全变更
- **先备份**：`D:\dsh\archives\display-layer\backup-<时间戳>\`（patch + package.json + home patch）。
- 改前读文件、**精确 edit 追加**（不整文件覆盖、不手改 `dsh-skin managed` 区块内部）。
- **YAML 校验 + 仅追加校验**：`node .tmp/display-layer/verify-patch.mjs`（借 CLI 自带 `js-yaml`：`C:\Users\76927\AppData\Roaming\npm\node_modules\@deepseek-ai\dsh\node_modules\js-yaml`）。
- 回退：`Copy-Item '<备份>\cordis.patch.yml.before-a-level' "$env:USERPROFILE\.dsh\profiles\desktop\cordis.patch.yml" -Force`。

### DSH 配置取证
- `dsh --profile web --dump-config`（合成树，可验证语法/键名；desktop 被 Electron 独占会拒绝）。
- `dsh --profile web --dump-config-schema`（配置 JSON Schema，重定向到文件再检索）。
- asar 读源：`node asar-ls.mjs "<app.asar路径>" "<innerPath>"`（引擎 `resources/app.asar`；读 `dsh/node_modules/@deepseek-ai/dsh-client-ui-*/lib/client.js` / README 找配置键与默认值）。

### 皮肤与主题
- 三包关系：`deep-whale-manager`（管理器，常驻）+ `maid-atelier` / `orca-link`（皮肤本体，互斥）。
- 切换：GUI「设置 → 皮肤管理」→ 管理器 `POST /api/dsh/skins` → 原子写 profile + home 两层 → 桌面端原地生效（**不用重启**）。
- 回退：切「官方默认」（两层全 `disabled: true`）。
- 版本：皮肤 peer `@deepseek-ai/dsh >=0.2.0-rc.2 <0.3.0-0`（当前 0.2.1-rc.5 满足，无需豁免）。

### 已验证口径
- 无 DOM 取证时只报「配置/注册已验证，渲染未在页面确认」，不把安装当视觉成功。
- 对账：每轮收尾 `tools/对账.ps1`（5 项，全 PASS 才收工）。

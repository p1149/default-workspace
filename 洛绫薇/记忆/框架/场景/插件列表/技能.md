# 场景 · 插件列表 · 技能

## 技能清单
- **插件盘点（只读）**：读 `~/.dsh/profiles/<profile>/package.json`（`dependencies` + `dsh.profile.bundles`）、`cordis.patch.yml`（`disabled` / 配置覆盖）、`node_modules/@local` Junction、`~/.dsh/plugins/`。
- **插件自述读取**：读各插件自己的 `package.json`（name / version / description / 默认 `enabled`），判断「装了 ≠ 启用 ≠ 生效」。
- **运行态验证**：端口探活（GUI 62852 / remote-control 7123）、宿主进程、注入痕迹（如会话开场简报）——配置态与运行态分开报。
- **只显示输出**：一句话总览 → 四分类表（生效 / 已装未启用 / 已建未装 / 皮肤）→ 证据行；**只读不落配置**，不改任何插件。
- **全局写入**：把盘点结果写成全局事实表 `框架/共享/插件清单.md`（含版本 / 状态 / 证据 / 风险），并登记 `场景索引` / `健康摘要` / `记忆` / `会话索引` / 看板 / 归档。
- **边界守则**：装 / 卸 / 启用 / 停用 / 改配置 → 移交「底层改造」；界面呈现 → 「显示界面」；本场景不出手改插件。

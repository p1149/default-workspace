# 场景构建规范

> 一个场景 = 一个项目 = 一个目录 + 六文件 + 两处登记。
> **分工**：定位卡由主人写；身份卡 / 场景画像由工具生成（含卡指纹 / 会话 / 布局）。

## 一、目录结构
```
框架/场景/<场景名>/
├── 定位卡.md     主人亲写：我是谁 / 我负责什么 / 边界（工具只建骨架）
├── 身份卡.md     工具生成：身份 + 卡指纹 + 会话 + 布局
├── 画像.md       工具生成：卡指纹 + 特征/状态 + 习惯/模式
├── 记忆.md       私有记忆：洛绫薇（本场景）维护（工具只建骨架）
├── 项目记忆.md   动态：项目变化 → 归纳沉淀
└── 技能.md       半静态：本场景私有技能清单
```

## 一·五、维护分工
| 文件 | 谁维护 |
|---|---|
| 定位卡 | **主人亲写**（工具只建骨架） |
| 身份卡 | **工具生成**（含卡指纹 / 会话 / 布局） |
| 场景画像 | **工具生成**（含卡指纹） |
| 私有记忆 | **洛绫薇（本场景）**：只放**场景指针**（项目 / 记忆文件 / 状态 / 下一步），见 `私有记忆规范.md` |
| 项目记忆 | 洛绫薇（走**写回链**：自动归纳 → owner 确认 → 写回；7 字段摘要 + 确认候选） |
| 技能 | 洛绫薇 |

## 二、工具生成字段说明
| 字段 | 写在哪 | 内容 |
|---|---|---|
| **卡指纹** | 身份卡 + 画像 | `SHA1(场景名 + 创建时间)` 前 12 位，唯一标识 |
| **会话** | 身份卡 | 绑定会话（建场景时可传 `-Session`，默认「待绑定」） |
| **布局** | 身份卡 | 图标 / 颜色 / 顺序 / 目标（面板布局参数） |

## 三、两处登记
| 位置 | 登记内容 |
|---|---|
| `框架/共享/场景索引.md` | 场景清单表格加一行 |
| `框架/洛绫薇的记忆.md` 关键事实 | 记录本次新增 |

> 场景面板（`scenes-panel` 插件）已于 2026-10-30 删除，不再登记。

## 四、一键构建

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\新建场景.ps1 `
  -Name "工具链" -Icon "🔧" -Role "开发工具维护" -Desc "构建/依赖/工具链" -Target "工具链" -Color "#8b5cf6" `
  -Session "（待绑定）" -Order 5
```

脚本自动完成：
1. 建 `框架/场景/<名>/` 六个文件；**定位卡只建骨架（【主人填写】）**；
2. **身份卡 / 画像由工具生成**（卡指纹 / 会话 / 布局自动写入）；
3. `场景索引.md` 插入一行；
4. （场景面板已删除，不再登记面板。）

## 五、删除场景
1. 目录移到 `D:\dsh\archives\scenes-removed-<日期>\`（归档不硬删）；
2. 从 `场景索引.md` 删行；
3. （场景面板已删除，无需删记录）
4. 更新 `框架/洛绫薇的记忆.md` 与 `健康摘要.md`。

## 六、边界
- 场景六文件**仅本场景读写**（`框架/规则.md` 第一条「场景主权」）；
- **定位卡只能主人写**，洛绫薇与工具不得代填；
- 全局层（法则/第二法则/规则/场景索引）对所有场景可读；
- 历史记录（archive/、会话索引）不改写。

## 七、项目写回链（见 `写回链规范.md`）
```
场景工作结束 → [1] 自动归纳（洛绫薇出候选）→ [2] owner 确认（主人批准/驳回/修改）
→ [3] 写回（洛绫薇只写批准项）→ [4] 记录（归档 + 记忆最近归档）
```
**铁律：未经 owner 确认，一律不写。**

## 八、配套规范
| 规范 | 管什么 |
|---|---|
| `README.md`（本文件） | 场景构建（六文件 / 两处登记 / 删除） |
| `私有记忆规范.md` | 私有记忆的结构与职责 |
| `写回链规范.md` | 项目变化怎么写回（自动归纳 → owner 确认） |

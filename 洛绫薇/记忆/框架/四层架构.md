# 洛绫薇 · 四层架构（治理 / 运行 / 审计 / 归档 + 显示层）

> 分工：**治理层定方向、运行层干活、审计层查账、归档层留底、显示层见事**。各层互不越界。
> **2026-10-30 19:30 补第五层「显示层」**（`框架/显示层.md`）：原四层缺「展示」一环，主人令「显示/界面（DSH GUI）管理与优化」后立层，现为**五层闭环**。

## 一、治理层（Governance）

| 项 | 规定 |
|---|---|
| 支撑 | 治理支撑 |
| 角色 | **命令台 = 洛绫薇**（治理层执行角色，只读代理；2026-10-30 15:30 主人指定继承，详见 `框架/命令台.md`） |
| 链路 | 主人 → 命令台 → **目标场景** |
| 职责 | **派单 / 催办 / 对账 / 审计** |
| 红线 | **不替目标场景改文件**（只读 + 派单；落地由目标场景自己写） |

### 治理支撑四件事
| 动作 | 做什么 |
|---|---|
| **派单** | 把任务分到目标场景 |
| **催办** | 盯进度，未完成就催 |
| **对账** | 核对「说做了」vs「真做了」（证据） |
| **审计** | 按审计层标准查账，出报告 |

### 派单闭环（治理层 → 目标场景）

```
命令台派单（任务看板「待办」）
   ↓
任务看板通知目标场景（tools/notify-scene.ps1 → 给场景绑定会话发 followup 消息）
   ↓
目标场景读看板「领取」（看板「领取」栏标记）
   ↓
干活 → 写「完成回执」
   ↓
命令台对账 → 销单
```

- **派单位置**：`框架/共享/任务看板.md` 的「待办（分发）」；
- **通知手段**：`tools/notify-scene.ps1 -Scene <场景>`（读场景身份卡绑定会话 → 调 `/api/notify` → 会话收到「请读任务看板、领取工作」）；
- **领取**：目标场景读看板后在「领取」栏标记，避免重复派单；
- **边界**：命令台只派人、不替目标场景改文件。

## 二、运行层（Runtime）

| 项 | 规定 |
|---|---|
| 定位 | **运行时 / 执行** |
| 组成 | **引擎 / 外壳 / 工具 / 插件 / 任务** |
| 负责 | **执行** |
| 约束 | **工具在代码仓外**；**升级不破坏数据**；**不替代记忆** |

## 三、审计层（Audit）

| 项 | 规定 |
|---|---|
| 定位 | **审计 / 只读** |
| 巡检范围 | **法则 / 规则 / 结构 / 索引 / 共享层 / 技能 / 归档** |
| 输出 | **只报告，不代改** |
| 追溯 | **写盘审计可追溯** |

## 四、归档层（Archive）

| 项 | 规定 |
|---|---|
| 定位 | **归档与历史** |
| 原则 | **自动快照 / 只进不改**（append-only，历史不可改写） |
| 内容 | **会话 / 备份 / 场景归档 / 文档台账** |
| 交接快照 | **只进不改** |
| 检索 | 需要时**按索引检索** |

### 归档内容
| 类型 | 存放 |
|---|---|
| **会话** | `~/.dsh/storages/session_projcache/sessions/` + `框架/共享/会话索引.md` |
| **备份** | `D:\dsh\archives\`（场景删除、回滚快照、安装包） |
| **场景归档** | `框架/场景/<名>/` 的历史与迁移前内容 |
| **文档台账** | `框架/archive/`（每轮交接记录） |

### 索引
- 会话索引：`框架/共享/会话索引.md`
- 交接归档：`框架/archive/`（按日期命名）
- 场景删除归档：`D:\dsh\archives\scenes-removed-<日期>\`

## 五、显示层（Display）

| 项 | 规定 |
|---|---|
| 定位 | **只读呈现层**——UI 只消费各层数据、不反向写业务真相 |
| 组成 | client 插件 / 侧栏 / 面板 / 主题皮肤 / 场景卡 / 聊天渲染 / 记忆注入提示 / 设置页 |
| 负责 | **看见**：样式 / 布局 / 密度 / 入口开关 / 显示性能 |
| 约束 | 不改引擎源码；不手写 profile 配置（先快照再改）；审美取舍交主人；「装了≠启用≠生效≠看见」 |
| 详规 | 见 `框架/显示层.md` |

## 六、四层关系（含显示层 → 五层闭环）

```
主人
  │ 下令
  ▼
治理层（命令台 · 只读代理）
  派单 / 催办 / 对账 / 审计 —— 不替目标场景改文件
  │ 派单
  ▼
运行层（引擎 / 外壳 / 工具 / 插件 / 任务）
  执行 —— 工具在代码仓外 / 升级不破坏数据 / 不替代记忆
  │ 执行结果 + 证据
  ▼
审计层（只读巡检）
  查 法则 / 规则 / 结构 / 索引 / 共享层 / 技能 / 归档 —— 只报告，不代改
  │ 报告 + 证据
  ▼
归档层（只进不改）
  会话 / 备份 / 场景归档 / 文档台账 —— 自动快照 / 按索引检索
  │ 留底数据
  ▼
显示层（只读呈现）
  GUI / 侧栏 / 面板 / 皮肤 / 场景卡 / 提示 —— 只消费不写回
```

## 七、边界红线

| 层 | 不许做 |
|---|---|
| **治理层** | 不替目标场景改文件 |
| **运行层** | 工具不替代记忆；升级不破坏数据 |
| **审计层** | 只报告不代改；写盘必须可追溯 |
| **归档层** | **只进不改**（历史不可改写） |
| **显示层** | 不反向写业务数据；不改引擎源码；不替主人做审美决定 |

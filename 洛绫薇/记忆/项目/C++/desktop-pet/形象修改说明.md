# 桌宠形象修改说明

## 0. 一句话定位

形象 **100% 在 `DrawPet()` 里**（`pet.cpp` 第 93–246 行），没有任何图片素材。改法永远是三步：
**改代码 → 重新编译 → 杀掉旧进程再启动**（没有热重载）。

## 1. 画布与坐标系

窗口逻辑尺寸 `180×180`，实际像素 = `S(180)`，经 `SF()`/`S()` 按 DPI 缩放（120 DPI 下是 225×225）。
所以**写尺寸一律用 `SF(数字)` 包起来**，或者用 `rx`/`ry` 的比例，别写裸的整数像素。

```
cx      = W / 2                                    // 水平中心
floorY  = H - SF(6)                                // 脚底那条线
r       = SF(44) * 呼吸系数                         // 身体基准半径（行 105）
rx      = r * squash ,  ry = r * (2 - squash)       // 挤压/拉伸后的横纵半径
bodyCY  = floorY - SF(8) - ry + bob                 // 身体中心纵坐标
```

所有部件都相对 `cx / bodyCY / rx / ry` 定位，所以改 `r` 就是整体等比缩放，不会错位。

## 3. 三层改法

### A. 只调参（最安全，5 分钟）

改上表里的数字和颜色，重新编译即可。**不要动结构**，比如别去动 `squash` 那两行。

### B. 改结构：加/减部件

新增部件只要插在 `DrawPet()` 的合适顺序里就行（**后面的盖住前面的**）：

```
投影 → 尾巴 → 耳朵 → 身体 → 脚 → 腮红 → 眼睛 → 嘴 → （帽子/围巾这类新部件）
```

插入点建议放在嘴那段（第 236–241 行）之后、"`ResetTransform`"之前。

### C. 换精灵图（要正式效果就走这条）

把 `DrawPet()` 的绘制换成贴图：

```cpp
// 初始化时加载（在 InitSurface 之后）
std::vector<Gdiplus::Image*> g_frames;
for (int i = 0; i < 12; ++i) {
    wchar_t path[64];
    swprintf_s(path, L"sprites\\idle_%02d.png", i);
    g_frames.push_back(Gdiplus::Image::FromFile(path));
}

// 绘制时（替换 DrawPet 的整个内容）
void DrawPet(Graphics& g) {
    g.Clear(Color(0, 0, 0, 0));
    const int idx = static_cast<int>(g_pet.t * 12.0f) % static_cast<int>(g_frames.size());
    // 注意：图片要按目标尺寸缩放，且透明通道会由 GDI+ 自动转换成 PARGB
    g.DrawImage(g_frames[idx], 0, 0, (float)g_W, (float)g_H);
}
```

要点：
- PNG 必须带 alpha 通道、每帧同尺寸
- 图片放**源码目录旁边**，不要放 D 盘构建目录（构建会被清）
- 精灵图模式下 `squash` 捏脸效果就失效了，压扁/拉伸要么预先画好帧，要么保留 `g.ScaleTransform` 做整体形变
- 加载失败要判空，否则 `DrawImage` 会画一片空白

## 4. 四个必须注意的约束

1. **尺寸一律走 `SF()` 或 `rx/ry` 比例**。写死 `44.0f` 这种裸像素，在 125% 缩放的显示器上会整体偏小、边缘也会被拉伸发虚。
2. **`squash` 是耦合的**：`rx = r*squash`、`ry = r*(2-squash)`。你把 `squash` 用完就丢会导致压扁时宽度也一起缩，看着像"整体缩小"而不是"压扁"。
3. **背景必须保持透明**。整块 `FillRectangle` 会毁掉分层窗口的透明效果；`g.Clear(Color(0,0,0,0))` 那句不能删。
4. **没有热重载**。改完必须 `cl` / `cmake --build` 重新链接，并**先结束旧进程**再启动——旧进程里跑的还是老的二进制。

## 6. 示例：加一顶帽子

在嘴那段之后插入：

```cpp
// ---- 帽子 ----
{
    const float hatW = rx * 1.15f;
    const float hatH = ry * 0.55f;
    const float hatX = cx - hatW * 0.5f;
    const float hatY = bodyCY - ry * 1.02f;

    GraphicsPath crown;
    crown.AddEllipse(hatX, hatY, hatW, hatH);          // 帽顶
    SolidBrush body(Color(255, 92, 110, 190));
    g.FillPath(&body, &crown);

    GraphicsPath brim;                                  // 帽檐
    brim.AddEllipse(cx - hatW * 0.62f, hatY + hatH * 0.62f, hatW * 1.24f, hatH * 0.42f);
    SolidBrush brimBrush(Color(255, 74, 90, 165));
    g.FillPath(&brimBrush, &brim);

    Pen edge(Color(255, 46, 56, 104), SF(2.0f));
    g.DrawPath(&edge, &crown);
    g.DrawPath(&edge, &brim);
}
```

注意 `SolidBrush` 要先建对象再取地址（`g.FillPath(&SolidBrush(...))` 传临时对象是未定义行为）。

# 附：图片形象模式（当前在用）

程序现在优先加载图片形象，找不到才回退到上面那套程序化橘猫。

## 素材与流程

```
desktop-pet\
├── assets\
│   ├── source.jpg    原始立绘（带紫色背景）
│   └── pet.png       抠好的透明 PNG（1360x2917）
└── tools\
    └── sprite_kit.py 抠图脚本
```

```powershell
# 从原图重新生成透明素材
$py = 'C:\Users\76927\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe'
& $py tools\sprite_kit.py assets\source.jpg assets\pet.png --max-side 1500 --seed 560,950 --debug
```

`--debug` 会额外输出 `pet_alpha.png`（掩膜）和 `pet_check.png`（叠在棋盘格上，检查边缘）。

## 抠图参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--tol` | 12 | 区域生长的相邻颜色容差；调大更容易连通、但也可能渗进角色 |
| `--max-side` | 1000 | 掩膜计算的长边；**这张图必须用 1500（≈原图）**，低分辨率会把手与身体间的缝隙抹平 |
| `--seed X,Y` | 无 | 手动背景种子，可重复。用于被角色轮廓完全包住的「口袋」 |
| `--grad-tol` | 0 | >0 时启用边缘约束（遇到强边缘停止生长） |

**这张图为什么要 `--seed 560,950`**：手臂与躯干之间的那块背景被轮廓围住了，边界播种永远够不到，必须从里面点一粒种子。

## 换一张图怎么做

1. 把新图存成 `assets\source.jpg`（或改脚本里的路径）
2. 先不带 `--seed` 跑一次，看 `pet_check.png`
3. 如果某块背景没去掉：用网格图定位坐标，加 `--seed x,y` 重跑
   （网格图做法：用 PIL 在局部裁切上每 50px 画一条线并标注坐标）
4. 重启桌宠即可，**不用重新编译**（素材是运行时加载的）

## 程序侧

- 窗口尺寸按素材长宽比自动算：`宽 = S(160)`，`高 = 宽×0.96×图高/图宽 + S(10)`
- CMake 构建后会把 `assets\` 整个拷到 exe 旁边，所以运行目录里必须有 `assets\pet.png`
- 加载路径依次尝试：`exe目录\assets\` → `exe目录\..\assets\` → `assets\`（相对当前目录）→ `desktop-pet\assets\` → 都失败则回退程序化橘猫
- 动画在图片模式下保留：呼吸起伏、挤压回弹、走路倾斜、左右镜像翻转
- 地面投影用椭圆压在脚底，掩盖「原图底边是裁切处」这个事实

## 已知限制

- **底边是原图裁切处**（大腿中段），不是自然的裙摆边。想更自然就把原图裁到裙摆再抠。
- 抠图对「深色衣料 + 深色背景」天然不友好，这张图靠 `--seed` 兜住了；换图如果出现衣服被吃穿，先把 `--tol` 调到 8~10。
- 图片模式下的「压扁」是整体形变，不是逐帧动画；要真动画得换成多帧 PNG 序列。
